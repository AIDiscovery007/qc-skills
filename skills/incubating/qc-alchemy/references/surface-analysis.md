# 首次关键表面分析与落实

首次分析参考图时使用，纠偏时复用同一组锚点。先看整体结构，再查看关键表面局部，最后回到整图核对焦点、颜色面积和纹理层级；不等用户点名皮肤或材料才启用。

## 选择与观察

按视觉焦点、风格辨识度、迁移相关性及误读风险选择表面。大面积背景与小面积焦点分别判断；皮肤、金属、玻璃、木材、织物、纸张、陶瓷、食品等只是可能对象，不逐类机械全查。无具象表面时分析色场、边缘或笔触即可。采用足以辨明关键特征的原图局部查看；需要时裁切放大，但放大不会创造原图缺失的信息。无需默认分割所有对象。

对所选区域只提取影响效果且可见的特征：
- 底色与叠加色层、受光/背光或局部红晕、反射/透射的分布，与 [颜色分析](color-matching.md) 联动判断是否需要分区取样。
- 明暗过渡的宽窄与软硬、光泽强弱、高光形状和反射连续性，如何随曲面转折。
- 纹理或笔触的形态、相对尺度、方向、疏密、规律性、对比和覆盖范围，如何随形体变化、在边界处结束。

尺度优先相对主体或邻近特征表达，如“比衣纹细、远看融合、近看可见”，不臆造微米、笔刷尺寸或制作参数。光滑且无可辨微纹理也是有效观察，不为显示分析细致而添加细节。局部不可辨时扩大查看或记录不确定，不推断看不见的毛孔、工艺或物理材质。

## 分清纹理属于哪一层

| 可见层次 | 需要辨明的关系 |
|---|---|
| 物体结构与纹样 | 褶皱、鳞片、雕花等如何构成形状或装饰，是否受用户结构锁定 |
| 材料表面微纹理 | 木纹、织纹、毛孔等是否可辨，密度与方向是否随表面变化 |
| 绘画媒介笔触 | 短线、点触、刷痕等如何塑形，与物体本身纹样区分 |
| 纸、布、木板等载体效果 | 哪些区域露出底纹，哪些被颜料或照片层覆盖；不可据外观断言真实载体 |
| 老化与成像痕迹 | 裂纹、磨损、颗粒与压缩噪声是否有可见依据、是否属于要迁移的效果 |

不把一种局部纹理扩散到全图，不用“古旧、油画、细腻”等标签自动补裂纹、画布纹或毛孔。混合媒介按区分配，皮肤也可有粗笔触或裂纹，但须来自本图依据或用户要求；不能将某个案例的光滑肤面变成默认规则。来源不明的痕迹描述其外观并保留不确定性，不强判制作原因。

## 提交前闭环

每个影响本次生成的表面锚点与颜色角色都须有去向：写入具体指令、因用户限制转译/省略，或因证据不足改用有依据的范围。少量必要记录可采用“区域与角色 → 观察依据/采样 → 提交句或处理理由”；普通任务简记即可，不另造大表或输出整份报告。

检查实际提交词，而非仅检查分析笔记：
- 描述是否包含区域、目标效果及形成关系？颜色在哪里铺开，局部色层如何过渡，纹理作用在哪里？
- 一个中位色是否混合了多个关键色层？亮面、红晕、阴影或反射需要分别表达时是否遗漏？
- 表面纹理的形态与尺度是否足以区别于最可能的误读？全局颗粒是否覆盖了应当采用另一种表现的区域？
- 旧肤色、光照、材质或全局肌理句是否冲突？重写原句，不在末尾追加相反要求。

发现关键遗漏或冲突，先修词再提交；不足以支持数值时用明确的颜色关系，不能假造 HEX。不是所有可靠样本都要写进 prompt，但决定效果的角色不能因已经采了其他区域就跳过。生成后的复核仍沿用这些锚点，分别比较颜色面积、明暗、光泽、纹理形态与尺度；文本落实不代表图像已经通过。
