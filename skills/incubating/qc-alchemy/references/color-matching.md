# 首次颜色分析与选择性约束

首次查看参考图并提炼风格时就判断颜色的重要性、取样价值及提示词分工；后续颜色纠偏沿用这套判断。适用于任意题材，不要求所有任务测量所有颜色。

## 1. 选出影响观感的颜色区域

综合面积与分布、视觉焦点、关键对比、独特性和迁移相关性排序：这个区域换色、变灰或面积缩小后，模板的主要效果是否仍成立？大面积背景、主体表面或发面通常优先；小面积发光物、功能标识或对比焦点也可能优先。具体颜色未迁移到目标的区域不必强加约束，用户明确保留项优先。

先区分需要控制的是色相、饱和度、明度、覆盖比例、色块位置，还是材质与照明的解释。像素颜色是成像结果，不能仅凭单张图反推出唯一的物理固有色或光源；生成时可以明确选择如何表现。

| 重要性与可靠性 | 行动与提示词 |
|---|---|
| 重要，区域可分离且代表色可靠 | 在首次分析中主动采样，将必要的代表色绑定区域、角色与覆盖范围 |
| 重要，单一色值不可靠 | 判断分区取样是否有帮助；优先表达色相范围、明暗分布、渐变、反射或透射关系 |
| 次要，色值可靠 | 通常概括色彩关系，不因易于取色就加入 HEX |
| 次要，依据不足 | 省略精确数值，保留必要的整体关系 |

可靠性需由以下步骤核验，不能由面积或醒目程度直接推定。可访问原始像素且采样有助于重要颜色判断时直接执行，不等待用户发现色差或再请求取色。只有显示预览、缺少可靠区域或工具不支持时，用可见关系表达并说明影响结论的限制。

## 2. 按画面选择颜色角色

| 画面条件 | 优先约束 |
|---|---|
| 均匀背景、平涂图形、包装主色 | 主色、覆盖面积与相邻色对比 |
| 人像、哑光产品或衣料 | 代表性中间调及受光/背光关系；不混入嘴唇、首饰或独立反光 |
| 天空、雾、渐变、水彩 | 主要色带、位置和过渡；不把多色区域平均成单一主色 |
| 金属、玻璃、透明织物 | 区分表面、反射、透射与叠层颜色；不能把高光或透见的背景当作材料本色 |
| 黑白主导画面 | 明暗面积、层次、轮廓接触关系；细微黑色色号未必影响结果 |
| 小面积发光焦点 | 发光色、光晕与周围暗面的对比；过曝白核心未必代表光源颜色 |

主色、高光、阴影不是所有任务都需要的固定三色表。按当前画法选角色，保留必要的材质和体积，不把具有光照变化的表面压成色卡。

先在关键表面上辨认语义色层，再决定样本数。皮肤的受光底层、局部红晕和肩胸过渡，或物体的涂层、反光带和透见背景，可能需要分别表达；一块“脸部”或“金属”中位色不能自动代表全部。已有大面积背景样本也不意味着小面积焦点分析完成。是否分区取决于这些差异能否改变生成结果，不固定按解剖部位或材料类别列色表。

## 3. 先明确色彩解释，再取样

读取原始文件的嵌入 ICC 等有效色彩信息，不优先从聊天预览、截图或压缩缩略图取色。区分“指定像素如何解释”与“转换像素数值”，不能仅换配置标签冒充颜色转换。无标签时优先查已知来源；仍未知可采用有依据的工作假设，例如按 sRGB 解释，但必须标明假设。

比较时统一并记录色彩空间和转换条件。用于 prompt 的 HEX 明确为 sRGB 表达；记录输入配置、输出空间、转换意图及使用的工具。保留原文件，只在分析副本或内存中转换，不自动对交付图片调色。

广色域转换到较小色域可能映射或裁切。大量通道触及边界、细节或颜色分布突变是核查信号，不是完整的超色域证明。映射后的代表色不能称为无损恢复的唯一原色，其饱和度也不能直接代表原始颜色的真实度。应明确它是供指定目标空间使用的值，并保留相关限制。

## 4. 选择语义区域与统计方法

先确定对象和颜色角色，再选矩形或蒙版。避开物体边界、头发、眼唇、文字、水印、独立高光、其他物体及透明覆盖；若这些效果本身就是分析对象，则单独分区。无需默认运行全图分割或聚类。

较均匀区域可取 RGB 各通道中位数来减轻孤立亮点和纹理影响，注明这是局部代表值，未必是实际存在的某个像素。多峰或混色区域应分区、保留多个代表色或描述分布，不能机械平均。需要样本中真实存在的颜色时可选有代表性的实际像素，并记录选法；方法服从问题，不固定一种统计量。

在同一语义和受光角色内，按需要检查邻近小区域或轻微移动、缩放采样范围，观察结论是否稳定；不跨入不同材质或光照区凑样本。参考与结果各自重新定位对应表面，同一坐标、归一化位置或图片尺寸不能代替语义对应和配准。

邻近数值稳定只能支持该角色内的重复性，不能证明样本覆盖了其他色层；结合 [关键表面局部观察](surface-analysis.md) 回看取样框。重要且可分离的角色应核对配置、代表性与邻近稳定性；渐变或混色不适合单值时记录范围和空间关系，不为凑稳定样本改采另一个颜色角色。

## 5. 说明可靠性的依据

分别检查区域纯净度、对目标角色的代表性、邻近采样稳定性、配置解释及色域情况。数值可复算与区域能代表整体是两个判断。可用“已核验、依赖假设、证据不足”记录各项，并说明原因；没有验证依据就不提供置信百分比，不以读数精确到一个字节暗示感知精确。

重要但依据不足的区域仍需强引导其颜色关系，不能因无法得出可靠 HEX 就忽略。存在明显色域限制时，可提供有条件的映射值或色彩范围，不能承诺原色像素复现。

## 6. 筛选提交与复核

按 [提示词结构](prompt-contract.md) 只写会改变生成决策的颜色约束：区域、颜色角色、覆盖范围、与相邻色的关系，以及必要的材质表现。高可靠的次要颜色也可不写。色号作为区域参考，不是强制填充每个像素的指令；不用固定数量配额，也不整表复制采样结果。

首次提交前逐个核对重要角色的去向：已有证据但未进入必要区域描述、只有色号没有覆盖关系、单值混淆色层，均须先修正。保留必要样本与提交取舍的简短记录，不能用“做过取色”或“含 HEX”替代语义覆盖检查。

先删除与目标冲突的旧颜色、光照或材质描述，再补新词。色差可能需要修正面积、曝光、透明叠层或光源关系，仅提高饱和度或罗列禁用色号未必有效。默认保留其他已接受的内容与结构，具体生成授权及有限纠偏按 [校验规则](evaluation.md) 执行。

复核默认用肉眼、局部 RGB/HEX 和必要的 HSV 趋势解释方向，不将 RGB/HSV 距离转换成感知相似百分比。低饱和或近黑区域的色相读数可能缺乏意义。

需要感知色差时可用 Lab/ΔE，但先统一色彩解释、参考白点、转换条件和语义区域，注明色差公式。针对原参考颜色与针对映射后目标颜色的比较应分开；不要先经有损色域映射再声称测得原始颜色差异。局部代表色比较不是整幅像素配准，不能套用跨题材通用通过阈值，也不能让单个色差分数覆盖构图、材质和面积问题。

最小取色记录：文件路径及版本/哈希、尺寸、输入配置或假设、目标空间与转换条件、区域语义和位置/蒙版、统计方法、代表值与实际检查到的稳定性/色域限制。没有测过的项目标为未验证，不编造完整证据。

工具接口可查 [Pillow ImageCms](https://pillow.readthedocs.io/en/stable/reference/ImageCms.html)，色彩评估与色域限制可查 [ICC FAQ](https://www.color.org/faqs/)。具体案例色号留在实验记录中，不作为新任务的默认色板。
