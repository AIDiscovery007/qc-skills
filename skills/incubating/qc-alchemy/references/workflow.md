# 通用分析流程

## 1. 判定任务与输入角色

| 意图 | 最少输入 | 产物与原则 |
|---|---|---|
| 还原参考图 | 一张参考图 | 保留关键内容、结构与画法，写具体复刻词 |
| 提炼通用风格 | 一张参考图 | 分离可替换主题与稳定视觉规则，给风格配方 |
| 以新主体重演模板 | 参考图 + 主体图片或文字描述 | 从目标选择身份线索，构图、姿态、可见度和表现可由模板重建；按用户限制分配 |
| 保留结构换画法 | 待处理图片 + 参考图 | 锁定用户指定的布局/形状，只迁移允许字段 |
| 定点纠偏 | 当前结果 + 修正要求；参考图有则用 | 只修偏差，保留其他已接受维度 |

用户说“逆向这张图”且无其他限制时，默认写还原该图的提示词；说“提取风格、给其他主体用”则抽象风格。不要把前者偷偷变成主体替换，也不要把后者写成只能画参考图内容的词。

“风格转换”本身不等于“所有结构不变”。结合用户目标与模板机制，区分重演模板和保留结构换画法；强调模板复刻时优先前者，明确要求原姿态、原场景不变时服从锁定字段。仅提炼通用风格而未给目标时，不预写一长串保留原图姿态、衣着和背景的强约束。决定会显著影响结果而上下文不足时再问，已明确的授权直接执行。

给每张图明确角色：整体参考、主体来源、构图参考、材质参考、配色参考、编辑目标。用户标注的角色优先，不按上传顺序猜内容。只有需要但未提供的图片才请求补充；文本主体描述也可以做适配。

## 2. 观察：内容、结构、视觉语言

首次分析按“整体结构 → 关键表面局部 → 整图回看”进行，按 [表面分析与落实](surface-analysis.md) 选择局部并区分颜色、光泽、纹理与载体层次。局部选择依据焦点、辨识度及迁移风险，不只看面积；不要求所有对象逐一放大。低清图、拼图、截图或带边框图先确定用户实际关注的画面；不要把浏览器按钮、平台水印或拼图分隔线误作艺术风格。不能辨明且会显著改变结果时再问。

- 内容：主体类别、数量、动作/状态、关键物件、场景、可见文字。非具象画面记录形状和色场，不强行找人物或故事。
- 结构：焦点、视角、比例、裁切、留白、对称与节奏、景深或平面层次、动线、网格、重复与遮挡。不要给平面图强加相机参数。
- 视觉语言：媒介表现、配色及分布、明度对比、照明、表面响应、笔触/线宽、纹理密度、清晰度、边缘过渡、排版。
- 关系：主体与底色怎么接触？轮廓由线、色差、遮挡还是模糊形成？透明物露出哪些后景？哪些材料分别作用在哪些区域？

选出约3–7个最影响观感的锚点；数量随任务复杂度调整。以相对位置和近似比例表达，不伪造测量精度。

锚点要说明效果如何形成，例如暗面隐藏细节、发光配件建立焦点、动作组织亮区，而非只写风格名称。用“去掉这个特征后还像不像模板”判断它是内容偶然项还是效果必需项；有目标主体时再判断承载位置与结构是否兼容，详见 [模板重演](template-reconstruction.md)。

### 首次分析即判断颜色约束

每次基于参考图分析或提炼风格时，主动识别决定观感的颜色区域，不等用户指出色差。综合面积与分布、视觉焦点、关键对比、风格独特性及迁移相关性判断重要性；大面积主色优先，小面积但决定焦点的颜色也可优先。再判断偏差风险来自色相、饱和度、明度、覆盖比例还是光照与材质解释。

重要性与取色可靠性分开判断。对重要且可分离的区域，在可读取原始像素时主动核对色彩配置并采样，按 [颜色分析与约束](color-matching.md) 评估代表性；重要但混色、渐变或取色依据不足的区域，先分区或用颜色关系表达，不强选精确值。次要区域通常概括即可。每次都做颜色判断，不要求每次都做复杂取色。

写词前选定少量真正影响生成的颜色约束，明确作用区域和覆盖范围；按语义角色核对覆盖是否充分，不能以已经取了几个大色块代替关键表面的色层分析。不要把全部采样值写入提示词，也不要因测得某种颜色就覆盖用户明确保留的色彩。取色依据不足时说明相关限制，不编造色号或置信百分比。

## 3. 分配字段与解决冲突

对相关字段记录“取自哪个输入/由用户指定、保留什么、允许改变什么”。无需输出一张满是空项的表。

字段包含主体特征、数量/角色、姿态或几何、视角、构图、背景、文字、色彩、材质、光影、细节密度、边缘。不存在的字段直接跳过。

用户硬约束优先于模板相似目标。源图不是天然高优先级：重演模式可重建布局；锁定布局模式则不能偷换机位。保留身份只锁定本次所选的身份线索，不能顺带锁死动作、曝光、衣着和背景。助手旧提示词中的限制不是用户硬约束。难以同时成立的要求要明确取舍，不声称全部满足。

多参考图按字段分工，不能把矛盾风格机械平均。用户说“一张管构图、一张管材质”就按其划分；未指定且不冲突时采用清楚的职责分配并简述假设，有关键冲突再问。不要编造工具不支持的数值权重。

## 4. 区分稳定规则与可变内容

还原模式保留具体对象；风格配方则分出：
- 可替换内容：主题、产品、人物、标题文本、场所等。
- 结构规则：占比、留白、前后层、节奏、方向、几何组织。
- 表现规则：配色关系、光影、材质、线条、颗粒及边缘。
- 适配条件：替换主体后哪些关系仍适用，哪些须重新判断。

例如“绿色花瓶在左下”是内容加位置；“低位单主体、上部大留白、主体与背景冷暖对比”更可迁移。是否保留绿色由用户希望复刻的风格范围决定，不自动删掉所有具体颜色。

## 5. 清理旧词、形成提交词

旧词是待审候选。删除与本次目标冲突的原句，再补新要求；不依赖末尾一句“优先执行”抵消互斥命令。检查材质描述中的隐含结构，如“剪贴白边”其实会改变边界。

不要用正则自动决定语义删留。无需旧词即可逆向；无需声称恢复了作者原prompt。目标模型未指定时输出通用自然语言，不添加特定平台参数；已指定时仅用该环境明确支持的语法。

按 [提示词结构](prompt-contract.md) 将字段归属与关键锚点转为对应模式的提交词，完成其中的压缩查漏及表面分析的提交前闭环；批量任务同时执行逐条适配检查，不能只拼接共享保留项和一段风格描述就视为完成。

## 6. 生成或交付

默认“逆向/分析/写词”只交付提示词。用户要求生成时按实际输入角色执行，并保存实际词、版本和条件。输入角色说明不得引用未提交的图片。

若目标生成阶段不支持图片输入，将必要的可见信息写进独立文本提示词，去掉“如图”等依赖；说明这是文字重建条件。重生成与编辑现有图分别记录，不能当成同一种复现证据。
