# 通用提示词结构

按当前任务选取模块，省略无关字段。不固定人像、双图、比例、语言或某个出图平台，也不把整份分析报告灌进最终prompt。

| 模块 | 要回答的问题 |
|---|---|
| 任务与输入角色 | 是还原、提炼、适配还是修正？每个实际输入负责什么？ |
| 内容与保留项 | 画哪些主体、状态和文字？用户锁定哪些特征？ |
| 空间或版式骨架 | 元素放在哪里？视角、占比、裁切、节奏、留白与层次如何？ |
| 分区域视觉语言 | 各区域采用什么配色、光影、媒介表现与表面响应？ |
| 细节与边界关系 | 什么覆盖什么？线/面、透明/反射、印刷/摄影如何衔接？ |
| 有针对性的防错 | 哪些少数误解最可能破坏这张图？ |
| 输出规格 | 用户需要的比例、尺寸、文字、背景及交付数量 |

## 从分析到提交词

结构用于落实生成决策，不以有标题、固定段数或出现关键词判定合格。默认按下述逻辑组织；用户指定格式或要求原样提交时优先服从。

1. **先定模式和归属。** 依据本次用户要求确定哪些字段保留、哪些重建、分别由哪个输入提供；不能由批量脚本默认“全部不变”。同批明确共享的限制可以复用，单条例外单独处理。
2. **将关键锚点转为指令。** 对每个适用锚点明确作用对象、目标效果及形成效果的关系。例如“冷蓝金属感”应落实为哪个表面、亮暗如何分布、反光沿哪里出现。锚点与用户限制冲突时选择兼容的转译或省略，并在需要时说明效果损失，不用互斥命令兼顾两者。
3. **按对应骨架成文。** 先写任务和输入职责，再写内容/结构，接着写大面积色彩与明暗、焦点与局部媒介关系，最后补必要防错和规格。复杂内容分成职责清楚的自然段；短任务可合并相邻模块。颜色就近绑定区域，不另堆色板；不把所有风格信息和禁止项挤成一个杂项段。
4. **压缩后查漏。** 同一约束集中表达一次；仅保留会改变生成决策的描述。逐项回查关键锚点、字段归属及相互关系，完成 [关键表面与颜色角色的提交前闭环](surface-analysis.md)，未写清就补具体规则，而不是补“严格遵守参考图”。分析笔记、置信记录与任务元数据留在正文之外，除非用户或执行工具确实需要。

## 单参考图：具体复刻

根据图片填写具体内容，默认输出一个可直接使用的完整提示词。若不确定生成时是否带参考图，正文写成可独立理解的描述；仅在确定带图时另加输入角色说明。

```text
生成[媒介/画面类型]，表现[主体、数量、状态及环境]。
以[视角或版式]组织画面：[焦点、位置、占比、留白、前后层次]。
[主要区域]采用[颜色、明度、材质与光影]；[次要区域]采用[对应表现]。
[关键线条/笔触/纹理/排版特征]。
[关键接触、遮挡与边缘关系]。
保持[决定相似度的具体锚点]；避免[当前任务特有的误解]。
[所需输出规格和确切文字]。
```

## 风格配方：给其他主题使用

将可替换项明确标记为变量，其余为从参考图提取的视觉关系。变量只存在于用户需要复用的配方中；若用户要直接出图，先按目标内容展开。

```text
主题：[SUBJECT]；文字：[TEXT，仅适用时]。
按[空间/版式规律]安排主题，与[背景/辅助形状]形成[比例和层次关系]。
主要色彩为[配色与区域分工]，明暗由[光源或平面色块]建立。
主体呈现[材料/画法]，背景呈现[材料/画法]；边缘通过[关系]形成。
细节保持[密度、笔触、纹理或字体视觉特征]。
适配时保留[核心视觉规则]，允许[内容变量]变化。
```

不把“复古包装风”压缩成只能画某款零食的prompt，也不把它泛化成没有具体视觉规则的“高级复古”。

## 多输入适配：角色说明加同一骨架

先选重演模板或保留结构模式，不自动附加“姿态、服装、背景、视角全部不变”。重演时写清源主体提供哪些身份线索、模板提供哪些结构与可见度；对承载效果的道具明确添加或替换的位置和作用，避免先禁止添加再要求同一视觉效果。模板不适配的元素说明如何转译或省略，不承诺省略后仍完全相同。

```text
输入[A]提供[目标主体/保留结构]，输入[B]提供[允许迁移的构图或画法]。
用户锁定：[具体字段]。可重建：[具体字段]。
将[目标内容]映射到[结构位置]，按下列规则完成：[空间、区域画法、接缝]。
```

编号必须与实际提交顺序一致。一个输入可兼任多个角色；没有主体图时可用用户的文字主体，不得虚构“图1人物”。

重演型提示词按“输入职责 → 身份线索 → 构图与姿态 → 明暗及遮挡 → 焦点载体 → 材质与细节”组织。把可见度写成可执行结果：哪些区域只能读到剪影、哪些区域允许结构细节、哪些是最亮焦点。不要用“像本人”“100%风格”替代这些决定。精确照用用户提供的提示词时不擅自补充；用户要求纠偏后再重写冲突内容。

人物姿态先分析整体关系，写入提示词时只保留决定当前动作的部分：承托与身体朝向、头相对胸廓的转向、关键肢体接触及视线目标。局部动作需要明确相对谁、朝向哪里；删除旧词中与新姿态冲突的头部倾斜、看镜头或完整展示双眼等要求。身份描述允许脸部投影、五官可见范围、衣领和发丝随新视角重绘；不把整份骨架分析或没有依据的角度数值灌进提示词。

### 保留结构换画法：专用骨架

用户明确锁定原结构时，按“输入职责与迁移范围 → 需保留的内容和空间关系 → 区域色彩与明暗 → 媒介、表面与边界 → 针对性防错与规格”组织。无需为了模仿模板而重建姿态；是否保留原光影、颜色、纹理和材质须分别判断，不能从“结构不变”推导出这些也全部不变。

```text
以输入[A]为编辑目标，保留[用户锁定的字段]；输入[B]提供[允许迁移的表现规则]。
画面维持[关键主体、位置/姿态、视角、比例和遮挡关系]。
[主要区域]呈现[主色、覆盖范围与明暗组织]；[背景/次要区域]呈现[对应表现]，两者形成[关键对比]。
[各区域的媒介、表面响应、线条或纹理]；在[接触/交界处]通过[具体方式]衔接。
[本例易发生的少数错误及其约束]。[实际所需规格]。
```

保留几何和物体存在，不等于逐点保留照片纹理；版画、剪纸等可将细节概括为对应画法，精确保留要求来自用户时再收紧。锁定外轮廓与手绘边缘并存时，说明前者约束整体形状，后者只改变局部笔触。模板机制依赖不允许引入的物件时，只迁移可兼容的表现，不承诺完整复刻效果。

## 颜色约束：筛选后写入

首次分析时按 [颜色分析与约束](color-matching.md) 筛选视觉主导色与关键焦点色，只提交会改变生成决策的约束。重要且有可靠采样依据的区域可加入标明 sRGB 的代表色；重要但单一数值不可靠时，明确色相范围、色块分布与明暗关系。次要色通常用自然语言概括，不把完整色板、采样坐标、统计量和置信记录塞进 prompt。

将颜色绑定到区域与作用，而非孤立列出 HEX：

```text
[区域]以[颜色描述，必要时附 sRGB 代表色]作为[平涂主色/中间调/高光/阴影]，覆盖[范围]；
与[相邻区域]形成[明暗、冷暖或色相关系]，通过[表面颜色/照明染色/反射/透射]呈现，保留[必要材质和体积]。
```

主色、高光、阴影只在各自影响效果且有依据时分别约束，不强制三色方案。色号指导主要区域的颜色关系，不要求每个像素相同；单色平涂、渐变、发光和透明层分别按实际画法处理。覆盖范围比多列色号更重要，避免把大面积主色仅画成一束边缘光。

清理与目标冲突的旧颜色、白平衡、光照和材质描述，再补新要求。将固有色与照明解释写为本次生成目标，不声称从图片测得了真实物理固有色。用户明确锁定的色彩或要求原样提交提示词时，服从其限制。

## 表面约束：按区域落实

将首次局部分析选中的表面特征写入对应区域，按需要使用“[区域]以[底色/色层分布]建立[明暗过渡与光泽]，叠加[纹理形态、相对尺度、方向和强弱]，覆盖[范围]并在[边界]衔接”。只选决定本图效果的部分，不强制填满所有字段；无法辨明微纹理时描述可见的光滑程度和光照响应。

物体纹样、材料微纹理、绘画笔触和载体痕迹分别归属；同一句“旧画肌理”不能替代各表面的不同画法。已有全局肌理句会冲突时改写其作用区域，避免靠末尾“皮肤例外”抵消。可靠色值也不能替代红晕、渐变、反光或透射的覆盖关系；数值证据留在记录中，正文只保留必要约束。

## 有效压缩与防错

“高清金属产品大片”信息不足；“单件小体积产品位于下部，顶部大留白，左侧宽条柔光在曲面形成连续高光，深灰背景与底面接触影”更明确。

“插画海报”不足；“上部双行大标题、中央扁平形块、下部小字；两种专色、粗细不均轮廓、纸面漏白、错版边缘”更可执行。没有看到这些结构就不要添加。

负面要求围绕实际易错点，不复制长篇通用禁词。参考图本来有描线、文字、硬阴影或颗粒，就不能照搬“不描边、无字、柔光、干净”。

## 批量输出：逐条适配

共用骨架和明确共享的用户要求，不共用未经筛选的主体限制、区域配色或防错清单。每条均需完成模式、输入角色、关键锚点与区域关系的判断；同一张主体图可复用事实描述，但允许改变的字段仍取决于本条任务。

逐条检查以下语义，不能仅抽查首条或检查标题齐全：
- 输入编号、主体类别及保留项正确；所有强锁定均有本次任务依据。
- 关键效果已有适用区域、分布和关系；不能只替换风格名称而保留通用形容词。
- 相关颜色分析已转为必要的区域约束；记录了取色不等于完成提示词筛选，也不以出现 HEX 判定通过。
- 关键表面已完成局部观察及提交闭环；没有将统一颗粒、裂纹或同一种光泽无差别复制到所有区域。
- 防错对应本条主体与实际风险；无人物的条目不带换装、表情等人物禁令。
- 没有复用造成的冲突、无关段落或重复限制；每条脱离批次说明仍可直接使用。

统一段落便于检查，但不等于分析充分。程序可核对文件、编号和版本，不能替代上述语义检查。修改已有实验词时另存版本；实际提交词与关联记录保持一致，不覆盖历史实验的输入证据。

## 建议交付

先给最终提示词；复杂任务可附简短的核心锚点、关键不确定项和输入使用方法。用户只要prompt时省略报告。精确文字用引号逐字列出；无法辨认时说明缺失或请求文本，不让模型猜字。

不要宣称未知的原模型、seed、LoRA、sref、CFG、焦距或字体名已被恢复。描述可见特征即可；用户指定某生成系统时，使用其已确认支持的格式。
