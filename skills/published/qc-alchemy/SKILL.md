# QC Alchemy — 参考图逆向与风格重构

从当前图片提炼生成决策，不从固定人物、风格名称或历史案例套答案。逆向产物是可执行的近似复刻方案，不能据一张图片还原唯一的原始提示词、模型、seed或制作流程。

## 执行入口

1. 按用户意图选择：**还原参考图 / 提炼可迁移风格 / 以新主体重演模板 / 保留结构仅迁移画法 / 修正已有结果**。单张参考图已经是有效输入，不要求补主体图。区分用户明确锁定的字段与先前由助手自行加入的限制；用户纠正取舍后清理旧限制。
2. 实际查看可用图片，按 [分析流程](references/workflow.md) 完成首次“整体结构 → 关键表面局部 → 整图回看”，联动判断颜色角色与表面表现；提交前核对重要观察已转为区域指令，不等待用户点名色差或质感。记录输入角色、硬约束和最重要的视觉锚点。多图按实际顺序标识，不能默认“图1永远是人物”。
3. 根据当前题材查 [场景适配](references/domain-adaptation.md) 的相关条目。先解释画面中的关系，再选择画法词；没有人物时不输出人脸规则，没有文字时不补排版要求。
   参考图加新主体、强调模板效果或出现“只像滤镜”的偏差时，读取 [模板重演与适配判断](references/template-reconstruction.md)，判断模板是否适配目标、哪些视觉机制需要改变姿态、可见度或配件才能成立。模板人物姿态可辨且允许重演时，按其中的整体姿态规则协调支撑、躯干、头颈、肢体和视线，身份特征随新视角重新表现。
4. 读取并执行 [提示词结构](references/prompt-contract.md)：先确定模式与字段归属，再按对应骨架组织提交词，逐项核对关键锚点是否写成了可执行的区域与关系。有旧词先清理冲突；没有旧词从观察起写。批量任务逐条适配与检查，不以统一前后缀代替分析。不依赖历史实验文件或某个指定图像模型。
5. 只有用户要求出图时，使用可用的 imagegen Skill；若不可用，交付提示词并说明执行限制，不谎称已生成。遵循用户指定的输入、数量和工具，按 [校验规则](references/evaluation.md) 检查结果并定点修正。

## 核心判断

- **内容、结构、画法分别归属。** 同一任务中，主体形状可能来自目标图，构图来自模板，色彩来自另一张参考图；用户明确锁定的字段优先。
- **先大后小。** 主次、机位、空间/版式、明暗色块决定整体，再处理材料、笔触、颗粒及接缝。不要用“高清、高级、95%相似”代替观察。
- **风格不是物体清单，也不只是表面画法。** 区分可替换内容与承载风格的形状、遮挡、道具及姿态；移除某个元素会破坏核心视觉机制时，重演模式应保留其作用并适配目标，不机械禁止添加模板配件。
- **保留身份不等于保留拍法。** 按用户目标选择五官、发型、轮廓、体型或产品几何等身份线索；姿态、衣着、场景与面部可见度单独分配。不得自动把源图所有字段锁死，也不得以模板相似覆盖用户明确保留项。
- **区域和关系要明确。** 谁覆盖谁、接触还是留白、面还是线、透明层还是反光、文字属于哪个层级。描边、模糊、留白都按当前参考图决定，不设统一审美禁令。
- **只陈述看得见的依据。** 精确字体、焦距、色号、物理材质和制作软件不可确定时，用可见效果描述；无法辨认的文字不编造。
- **范围与质量分开。** 可以分析任意题材，不代表所有参考图都能同等精确复刻；说明重要不确定性，不保证像素一致或固定相似率。

历史复盘仅在需要解释来源时读取 [机制与证据](references/evidence.md) 及其中的案例链接。运行新任务无需加载15种历史案例或证据索引。
