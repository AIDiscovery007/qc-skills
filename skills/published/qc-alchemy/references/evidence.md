# 机制与证据：为什么这轮更接近模板

本文仅记录最初双图人像实验，解释方法来源，不限定通用Skill的输入和题材。历史 [15种案例](casebook.md) 与 [来源索引](source-index.json) 只用于追溯。通用化后新增的单图逆向、跨题材分析和多参考图分工，是流程扩展，不能用本实验代替其实际出图验证。

通用化后另以未进入原15种样本的两张参考图做独立提示词试用：344室内图单图复刻、348线稿研究图提炼风格并适配文字主体“台灯”。执行者只读运行指导与两张图片，未读历史案例或旧提示词；两种任务均能产出提示词，未索要人物源图，未将原图双螺旋强行带入台灯。完整试用记录保存在项目 `output/skill-review-20260924/generalization-check.md`。此次没有实际出图，只支持单图入口和跨内容映射可执行，尚不证明所有题材的视觉效果或多次生成稳定性。

## 回顾过程

1. 初始比较包含已有词与新逆向词，以及是否加入风格参考图两个输入条件。用户选择已有词加参考图作为后续方向。
2. 新逆向Skill退出当前流程，保留已有词的色彩、笔触、材质和光影描述。
3. 发现旧词反复锁定原姿势、原背景、原服装，并禁止新增模板元素。402不能改侧脸，381不能加帽或隐藏五官。这与用户的模板复刻目标冲突。
4. 为15种风格补充具体姿态与构图要求，解除冲突。原图提供主体身份，模板提供画面组织；同一修订词分别跑单图与双图，共30张。
5. 404再从局部边界纠偏：删除沿人物描蓝线、白边、轮廓云，改为独立蓝色背景面与人物直接遮挡；两种条件各再生成一张。当前30个展示位置使用404最新版本，先前两张保留为历史文件。
6. 用户反馈最新提示词较精准，并明确双图加词表现最好。此Skill围绕该路径提炼，不恢复新逆向词比较。

## 结构上的原因

**输入职责变清楚。** 两张图本来会提供不同的姿势、环境和主体。分字段说明来源，减少“到底照着哪张图画”的歧义。

**从外观迁移变为允许重构。** 原提示词把场景空间固定了，只能改变表面。移除限制后，模型才被允许采用模板的机位、裁切、人物占比和背景元素。这是任务定义变化，不只是润色措辞。

**空间锚点比风格名更可执行。** “绿色超现实”留下很多可能；“左侧脸、头肩、肩线右下、粉纱颈前到耳后”约束了具体画面关系。它们决定大部分整体观感，材质词再负责细化表现。

**身份保存有选择性。** 人的身份不需要绑定其原坐姿或原房间；但抽象、藏脸越强，可用身份线索越少。381明确选择了轮廓，避免模型为辨识度自动补五官。

**图像与文字互补。** 模板直接呈现难以完整言说的形状、比例、纹理和配色；文字说明哪些要迁移、哪些不要复制、原图主体如何进入模板。双图不是冗余输入，文字也不是图像的逐像素替代品。

**局部关系控制解释。** 404说明模型可能把同一蓝色解释为背景、描边或投影。指出前后关系和接触方式，比追加“自然、高级、高清”更有针对性。

以上是对输入、提示词和输出关系的合理解释，不是对模型内部机制的直接测量，也没有证明每条改动独立贡献多少效果。

## 证据范围与限制

- 15个当前修订词均已按清单定位；404取 `revised-prompt-v3.txt` 及实际提交的 `.v3.submitted.txt`，不是旧版。文件来源及SHA-256见 `source-index.json`。
- 使用的是同一张 `hanfeng-influencer-06.jpg` 原图；尚不能推断适用于所有人物、产品或动物。
- 当前30个位置都有输出。成功出图不是质量通过；每种条件主要是单个样本，未估计多次运行的稳定率。
- 用户判断和可见构图变化支持当前方向；没有盲评、独立相似度标注、固定seed控制或严格逐因素消融。
- 15个提示词的多项约束同时变化，不能将全部提升归因于某一个句式。404是更集中的局部修正，但仍受随机生成影响。
- “95%以上”是用户提出的视觉目标，未测量为客观百分比。Skill压缩后的新任务表现还需实际验证。

创建时另做了一次独立执行的提示词试用：404模板双图重构，以及402模板仅迁移颜色/材质、锁定原姿势和室内。执行者查看原始输入，产出了两份提示词，没有出图；能分别采用模板构图及遵守用户的布局锁定。试用发现入口对局部迁移的描述含糊，已修订。执行者读到了Skill内的案例摘要，因此这属于已知案例的流程回归，不是严格盲测或跨模板泛化证据。

## 真正要复现的能力

可复用的是“字段归属 → 模板关系观察 → 主体映射 → 冲突清理 → 具体提交 → 视觉检查 → 窄范围纠偏”。

不固化女性、黑短发、3:4、15个风格码、具体配饰或统一不描边规则；不把漫长旧词机械拼接成一个总提示词。减少每次需要重新猜的决策，并保存实际输入与版本，才能让后续失败可定位、改进可积累。
