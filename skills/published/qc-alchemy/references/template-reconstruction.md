# 模板重演与适配判断

用于参考图加新主体、追求模板效果或纠正“只是滤镜”的任务。目的不是复制模板所有物体，而是找出其视觉效果依赖什么结构，并让新主体承担相同作用。

## 1. 先判断模板能否承载目标

先描述实际画面：是否有人或其他主体、主要形状与空间关系、焦点由什么产生、哪些细节可见或隐藏。风格名称只作概括，不能代替这些观察。

- **可直接适配**：目标与模板有相应的主体结构，可重演姿态、构图和区域画法。
- **需要转译**：题材不同，但色场、轮廓、线面、材质或空间关系可以映射到目标。说明哪些关系可迁移、哪些不能照搬。
- **与保留要求冲突**：模板效果依赖目标不允许改变的结构、遮挡或可见度。服从用户约束，说明最主要的效果损失；目标未明确时再澄清。

模板有人不代表适配任意人像；模板无人也不代表不能用于人像。例如抽象图形可用人物剪影承载色块，但不能据此声称复刻了原画的全部几何。产品的透明材质也不天然意味着应把人的身体透明化。

## 2. 找到效果必需项

对重要特征做删除判断：去掉它后，模板最突出的视觉效果是否仍成立？

- 仅负责题材叙事的物体可替换。
- 负责主体轮廓、遮挡、焦点或光学效果的形状和配件可能需要保留其功能。
- 动作会改变明暗面积、亮区位置与负空间，也可能属于风格的构成条件。

例如某模板的横向发光配件既隐藏五官又建立唯一亮焦点，只复制其颜色到皮肤无法复现该机制。另一个模板的核心若是自然面容与柔和日光，就应保留可见面部，不能套用藏脸规则。

判断结果写成区域关系：大暗面在哪里，最亮焦点如何形成，次亮区与焦点的距离和比例怎样，背景承担什么对比。再选择具体画法与纹理。

## 3. 分开身份与表现

从目标中选择本次仍需可辨认的线索；只保留会实际呈现在结果中的特征。

| 字段 | 判断方式 |
|---|---|
| 身份线索 | 人物可用五官、发型、头形、肩颈和体型；产品可用轮廓与关键部件。按任务选择，不全量机械锁定 |
| 姿态与机位 | 重演模式以模板视觉结构为目标调整；用户明确锁定时保留 |
| 面部或表面可见度 | 明确可见、简化、阴影吞没、遮挡或抽象化的区域 |
| 服饰与道具 | 分清身份标志、效果载体和偶然内容；允许在已授权的重演范围内重建效果载体 |
| 背景与光影 | 判断原场景是否是用户保留项；非保留项可由模板重建 |

用户允许改变姿态和隐藏脸时直接执行，不再次索要同一确认。不能因保留人物身份就坚持原姿势，也不能为追求模板而删除用户明确指定的发型或形体。

脸被隐藏后，只能评价仍可见的轮廓与体态保留程度；不要声称凭这些线索验证了精确面部身份。模板遮挡会盖住唯一身份线索时，明确这一限制或按用户目标调整遮挡。

## 4. 整体姿态重建（人物适用）

模板有人物、姿态可辨且任务允许重演时，先从整体逆向动作，再分配身份特征。分析深度取决于可见范围：全身看支撑与肢体，半身看躯干和头肩，头像只看可见的头颈肩；遮挡部分区分观察与合理补全，不虚构精确骨架。用户锁定原姿态时，以原图为姿态来源；模板无人时跳过此步骤。模板有刻意夸张或超现实变形时，先判断它是否属于用户要迁移的表现，不能一律修正为写实人体。

从以下关系中选择决定当前动作的部分，无需每次全量输出：

1. **观察视角与支撑**：身体如何被观看，站、坐、倚靠或悬浮，重心与承托面在哪里。
2. **骨盆、胸廓与肩线**：各自朝向、倾斜和相对转动，四肢从哪里连接；不以笼统的“侧身”代替必要的方向关系。
3. **头颈与躯干**：头相对胸廓如何转动、低垂或倾斜，颈部如何承接下颌与肩胸。正常回头和身体扭转可以成立，不要求头身永远同向。
4. **肢体与接触**：沿肩—肘—腕及髋—膝—踝理解可见动作，交代必要的承重、接触、交叠与悬空关系。
5. **视线与动作目标**：看向谁或什么，是否与手部动作呼应；眼睛转动与头部转动分开判断，不默认看镜头。

区分画面方向、人物自身左右与相对躯干的转向；提示词用清楚且一致的参照，无法辨认身体左右时可用画面位置或动作角色，不猜解剖侧别。不从平面参考图推定精确关节角度。

**身份特征随新视角重新表现。** 保留脸型、五官特征与发型，不等于保留源照片的头部角度、脸部二维轮廓、双眼可见面积或发丝落点。换姿态后同时协调头颈、肩胸、衣领及头发遮挡；可见的身份线索应符合新视角，不为展示某个眼睛颜色或完整五官强行转向观者。近景补全全身属于新构建，不能宣称还原了不可见的真实体型。

先写连贯的整体动作，再把局部特征放入该动作；避免将来源头部的倾斜和视线直接接到模板身体。仅写“自然姿势”“轻微转头”“避免错误肢体”不能替代决定姿态的关系。

## 5. 编写与纠偏

使用 [提示词结构](prompt-contract.md) 的重演骨架。将关键机制写成直接可执行的区域描述，删除与新分工相反的旧句子，不在旧词末尾不断叠加优先级。

出图后按 [校验规则](evaluation.md) 对照三类输入与输出，先比较整体剪影、明暗和亮区布局，再比较细节。修正要针对最重要的机制缺失，不能用增加颗粒、锐度或风格形容词掩盖结构偏差。

高相似要求表示应更严格地落实模板的核心锚点，不意味着能保证像素相同。换主体本身就会改变画面；说明保留项与模板效果的取舍，避免伪造相似百分比。
