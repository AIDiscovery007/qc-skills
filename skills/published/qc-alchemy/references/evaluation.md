# 通用校验与纠偏

## 出图前

核对任务模式、实际输入与角色、用户保留项、最重要的视觉锚点、文字、区域材质和边界关系。没有人物时跳过脸部检查，没有文字时跳过排版文字检查。只写提示词时在这里结束，不虚构出图验收。

检查冲突：固定布局与换机位是否并存？主体结构是否被材质词偷偷改形？平面表达是否混入写实景深？无描线是否又要求贴纸白边？去除冲突后再提交。

重演模板时另查：原姿态或原场景是否被无意锁死？隐藏面部是否仍要求清晰五官或正面补光？风格焦点依赖某个配件时是否又禁止添加？身份线索是否被模板服饰完全盖掉？这些限制应追溯到用户要求，不能把助手旧词当成不可改的约束。

人物换姿态时，核对头、胸廓、骨盆及视线方向是否被统一规划，支撑与关键接触是否成立；身份描述是否暗中保留了源照片的头部倾斜、脸部投影或看镜头方式。区分模板可见依据与遮挡部分的补全，不把正常回头误判为必须头身同向。

颜色检查从首次分析开始：主导色、关键焦点色及其覆盖范围是否已识别？重要且可采样的区域是否主动核对过配置与代表性？提示词是否只保留必要的颜色约束，并说明各自作用区域？数值可靠性不足时应改用关系或范围，不能用精确写法掩盖不确定性。用户有色彩保留要求时，检查其与模板配色的取舍。

首次提交前执行 [关键表面闭环](surface-analysis.md)：整体、局部与整图回看是否实际完成？所选表面的关键色层、明暗/光泽、纹理形态与尺度是否转成区域指令或有依据的取舍？只有背景取色、只有一个混合部位样本或宽泛的“细腻质感”不能代替此检查。关键遗漏、采样不具代表性或纹理层次冲突应先修正，再交付词或生成；不等用户发现偏差后补做。

## 出图后：按内容动态选项

| 维度 | 观察内容 |
|---|---|
| 内容与保留项 | 主体类别、数量、几何、动作、关键特征是否符合用户要求 |
| 结构 | 视角、比例、布局、裁切、负空间、动线、透视或平面层次 |
| 色彩与明暗 | 大色块分布、对比、光源、曝光或平面色阶 |
| 媒介与材料 | 摄影/绘画/图形语言、反光、粗糙度、笔触、纹理密度 |
| 局部关系 | 接触影、遮挡、透明叠层、边缘、背景面与轮廓线 |
| 表达精度 | 抽象级别、可见细节；人物身份或产品结构仅在适用时检查 |
| 字形与排版 | 需要的文字是否准确，层级、字号比例、字距和位置是否相符 |

先解决会改变整幅画面的大问题，再修微小纹理。必要时用“通过/部分/失败/不适用”记录；不要把主观评分当客观相似百分比。

同时对照模板、来源与结果：模板评效果，来源评所选身份线索，结果评两者实际落实情况。先缩小看剪影、明暗面积、亮区位置与姿态，再看遮挡、边界、材质和纹理。仅颜色和颗粒接近、视觉结构仍跟随原照时，不能判为模板重演成功。每个重要差异记录模板状态、输出状态及下一步改动；“95%/100%”转为具体锚点目标，不作为未经测量的交付承诺。

人物姿态另查头—颈—肩胸的连接、躯干与骨盆的转动、四肢连接和承托、视线与动作目标。衣领、下颌和头发遮挡可辅助判断，但遮住的连接不能声称已验证。识别“源图头部姿态直接接上模板身体”的观感；区分合理回头、风格化夸张和不连贯的局部拼接。出现偏差时联动修正相关的头颈、肩胸、衣领及发丝遮挡，不能只旋转脸或用头发掩盖问题。

### 颜色复核

先按首次分析选定的颜色角色比较色相、饱和度、明度、覆盖面积与相邻色关系，再判断材质和光照是否被误读。局部色值更接近不能代替整幅观感、结构及其他保留项检查；颜色面积不足、光源改变或透明层叠色也可能造成偏差。

需要数值复核时，沿用明确的色彩解释、转换设置、采样方法和语义受光角色。构图变化后重新核对区域，不能将相同尺寸或坐标视为自动配准；区域变化需记录。指标选择与色域限制见 [颜色分析与约束](color-matching.md)。没有实际测量就不报告数值改善，不用单一区域或 RGB/HSV 距离推算整幅相似百分比。

### 表面复核

沿用首次选择的同一组锚点，分别检查颜色面积与色层位置、明暗过渡、光泽响应、纹理形态/尺度/方向及覆盖边界。先整图确认层级，再局部检查；肤色接近但笔触变成裂纹、金属反光接近但表面变成磨砂，仍须记录为不同偏差。模板没有可辨微纹理时，不以新增细节作为改善。记录残余问题及实际检查范围，不用一次结果证明规则的因果或稳定性。

## 有限修正

找到影响最大的一个偏差及其原因，删除冲突或补具体关系。已有生成授权时，可针对明确偏差做一次修正并复查其他保留项；仍未满足则报告剩余问题，不自动无限重抽。用户已指定更大迭代范围时遵循该范围。

“复刻相似”与“遵守用户保留项”分开评价。锁定原空间的迁移不能为了模板相似擅自换背景；抽象藏脸不能同时要求写实五官完整辨识。

颜色偏差先按类型定点修正相关区域的颜色、覆盖或材质语义，保留已接受的其他分工。按已有授权的数量生成并复核，不因色号尚未命中而自动继续抽图或改成后期调色。仅分析或写词时不启动生成。

## 记录与更新

保存最终实际词、输入顺序和角色、输出、条件、修正原因；批量任务按需保存清单与哈希。更新结果页时图与词同步。不要声称工具未暴露的模型快照或seed相同。

用参考图生成、纯文字生成、编辑已有结果是三种不同条件。提示词草稿不是已完成的图像实验，结构校验也不等于视觉通过。

有取色时另存可复核的配置、区域、统计方法、代表色及限制，最小记录见颜色分析文档；这些证据不必写入生成提示词。修改颜色词时记录实际差异，若同时改变色号和区域/材质语义，不把改善单独归因于 HEX；不声称未控制的 seed 或模型快照相同。

## 验证通用性

跨场景验证应包含未参与规则提炼的参考图，例如产品摄影、空间、风景、排版和抽象图形；分别检查单图逆向、可迁移风格、主体适配、锁定结构和多参考图角色。另检查隐藏脸与清晰脸两类模板、无人模板向人像适配，以及用户明确禁止改姿态的情况，确保不会把某次成功的藏脸、配件或改姿态固化为通用要求。一次成功不能代表整个场景。

只写词的试用用于检查指令分工、事实与冲突；验证生成质量和随机稳定性需要真实出图及同条件重复。额外出图数量与成本属于该次测试范围，不因修改Skill自动执行。低清参考、不可读文字、被遮挡的结构及生成工具限制应具体说明。

姿态规则的验证应覆盖侧坐、合理回头、头像或遮挡输入、锁定原姿态及刻意夸张等不同条件。用失败案例复测时尽量保留输入、场景和画法，只修改相关姿态及身份约束，记录实际变化；单次改善只能支持该案例，不能证明普遍有效或完全排除生成随机性。

颜色规则先用静态材料检查主导平涂色、小面积发光焦点、渐变、反射/透射、无配置或色域边界等情况，验证首次主动判断、取样选择和提示词筛选是否合理。真实生成验证与静态检查分开记录，数量服从用户授权；单次成功不证明跨题材稳定性，固定案例色号不得变成默认色板。

表面规则用已有失误案例回查“观察 → 角色/纹理分层 → 提交句”的缺口，再选少量不同表面做首次静态分析，例如反光表面与无可辨微纹理的光滑表面。检验是否主动分区、选择性取色并给出可执行描述，不只匹配标题或术语。记录实际做过的检查；静态回归不是独立生成验证，也不能据单例断言所有历史任务都漏做取色。
