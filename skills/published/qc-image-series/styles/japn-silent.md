# japn-silent Style

## Style Card

- Style id: `japn-silent`
- Aliases: `japn-abstract`, `japn-wordless`, `无字抽象`, `极简无字`, `抽象极简`
- Text policy: textless
- Use when: the user wants a quiet, premium, minimalist, abstract series where the source meaning is carried by symbolic objects instead of readable text.
- Do not use when: the image must communicate exact claims, numbers, names, dates, quotes, or social-cover hooks through visible words.

## Core Look

- Silent japn-tech cousin: warm empty field, one precise symbolic machine-object, sparse marks, no readable text.
- The image should feel like a premium editorial object study, not an explainer diagram.
- Use a single decisive object or relationship per image: stair, split core, pressure gap, signal path, empty socket, isolated red block, cut line, or broken trajectory.
- Keep 70% or more of the canvas quiet background.
- No frames, cards, panels, UI chrome, dashboards, screenshots, badges, labels, captions, letters, numbers, or glyph-like fake text.

## Palette

Use these roles consistently across the full set:

| Token | HEX | Role |
| --- | --- | --- |
| BG | `#F2EDE4` | warm off-white field |
| INK | `#1A1A1E` | sparse linework |
| DARK_BLUE | `#1C2333` | main machine mass |
| BONE | `#E8E0D0` | quiet secondary planes |
| CRIMSON | `#C0392B` | one tension point |
| CYAN_DIM | `#2A6B7C` | signal or direction mark only |

## Shape Language

- Use hard-edged cel-shaded forms with thin ink outlines.
- Use no more than one main object, one secondary mark group, and one CRIMSON accent.
- Replace claims with visual metaphors: growth as ascent, risk as gap, regulation as narrowed gate, compute as weight, context as external memory block, speed as stretched trajectory.
- Empty space must do real work: isolation, distance, pressure, or hierarchy.
- Avoid realistic portraits, literal screenshots, charts, and readable typography.
