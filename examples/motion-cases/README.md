# Motion cases · qc-motion-design

案例已随 skill 打包，安装 `qc-motion-design` 即可获得完整代码、素材、原文索引和实现提示词。

**[使用说明与案例源码 →](../../skills/published/qc-motion-design/assets/motion-cases/README.md)**

在仓库根目录运行 `python3 -m http.server 5173 --bind 127.0.0.1`，打开 <http://127.0.0.1:5173/examples/motion-cases/>，即可跳转到案例页面。

首页展示素材保存在 `media/`：五个进阶案例 GIF。GIF 按原 CSS/WAAPI 动画时间轴每 20ms 采样，分别采集展开与收起，保留原始缓动，并在端点停留 650ms；受 GIF 格式限制，375ms 的错峰时间轴量化为 380ms。素材仅供仓库展示，不随 skill 安装。
